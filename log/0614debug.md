# 0614 调试与文档同步记录

本文记录 6 14 前后一轮用户进程调度收尾与文档更新。叙述采用书面语；对照代码处保留必要符号名。

## 一、背景与目标

6 13 已完成内核上下文切换的前两阶段（存储、阻塞唤醒）。本轮完成第三、四阶段：统一由调度器栈分发就绪进程，删除协程式用户入口与 longjmp 分发残留，并将退出/让出路径改为经陷阱返回函数回到调度器。交互式终端与管道自动化测试均已通过。

---

## 二、内核变更摘要

### 2.1 删除 longjmp 分发（阶段 3a–3c）

| 项目 | 说明 |
|------|------|
| 删除内容 | 调度模块内 setjmp/longjmp、独立返回栈、进程控制块中的 longjmp 标志与返回上下文 |
| 保留 | 专用调度栈、调度器内核上下文、基于汇编的上下文切换 |
| 布局 | 进程控制块缩小，用户陷阱帧相对栈顶偏移改为 `0x11a0`（汇编入口同步修改） |

### 2.2 删除协程式用户运行（阶段 4–5）

| 项目 | 说明 |
|------|------|
| 删除 | 旧的用户运行入口、深度计数、保存的 C 标签续体、从阻塞中强行跳回的逻辑 |
| 新增 | 首次运行入口（调度器切换进入）、陷阱返回入口（退出/让出/_fault 后切回调度器） |
| 保留 | 陷阱帧栈恢复用的保存寄存器字段；用「用户空间会话中」标志替代原深度 guard |
| 等待 | 父进程等待子进程改为仅睡眠循环，不再在等待路径上嵌套调度 |

### 2.3 当前调度路径（简述）

- **新就绪进程**：调度器选中 → 上下文切换 → 首次运行 → 进入用户态。
- **阻塞唤醒**：睡眠队列 → 上下文切换回阻塞点 → 系统调用返回 → 用户态继续。
- **退出/让出**：陷阱处理准备内核返回 → 陷阱返回入口 → 上下文切换回调度器。

### 2.4 测试

| 方式 | 结果 |
|------|------|
| 管道 `AUTORUN=ipc_echo` | 通过 |
| 交互式终端 `ipc_echo` | 用户确认通过 |
