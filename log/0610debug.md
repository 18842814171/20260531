## 二、内核观测日志（宏开关）

### 目标

参照模拟器项目中「编译期开关 + 分类宏」的做法，将原先分散的直接调用统一为宏；关闭调试构建时不产生串口日志开销。

### 要点

| 项目 | 说明 |
|------|------|
| 构建开关 | 默认 `make` 开启；`make DEBUG=0` 关闭全部观测输出 |
| 宏分层 | 通用事件宏、按子系统划分的快捷宏（启动、陷阱、进程、内存等）、条件宏 |
| 实现位置 | 声明于头文件，格式化输出仍由单一实现模块完成 |
| 调用方式 | 启动、陷阱、系统调用、内存管理等处的散点调用已改为宏 |

### 与串口的关系

观测内容仍以「固定前缀 + 一行 JSON」形式写入与 shell 相同的串口；未增加独立硬件通道。主机侧或网页侧需自行分流。

## 三、网页前端与后端分流

### 背景

浏览器通过 WebSocket 连接后端，后端在伪终端中启动虚拟机。内核观测行与普通 shell 输出混在同一字节流中，若全部送入终端区域，会出现 JSON 与登录提示交织、前端正则过滤不稳定等问题。

### 后端

在读取伪终端数据时增加按行分流：以「观测前缀」开头的完整行解析为结构化消息，经 WebSocket 以独立消息类型发送；其余行作为普通终端输出。不完整行暂存，避免截断 JSON；非观测内容的半行等待换行后再下发。

### 前端

| 消息类型 | 展示位置 |
|----------|----------|
| 普通输出 | 左侧终端 |
| 观测事件 | 右侧事件气泡列表 |
| 快照 | 右侧（汇总类卡片） |

终端在检测到「欢迎进入 shell」类固定文案前不刷屏，避免启动阶段日志干扰；欢迎语可能跨包到达，故采用累积缓冲再判定。用户在输入框提交的命令在 shell 就绪后于终端本地回显一行。

### 部署

后端默认监听本机 5000 端口；对外可由反向代理映射至 3333。启动脚本中强制以非采集模式启动虚拟机，分流完全由 Python 后端完成，不依赖管道上的独立采集脚本。

## 四、网页界面与交互

- 启动页：登录表单，用户名限定为 root，会话信息存于浏览器本地存储。
- 桌面页：侧栏（桌面快捷方式、文件列表）、中间文件预览与终端、右侧全高事件列。
- 图标统一为 Bootstrap Icons；示例页保留静态气泡样式供对照。
- 文件 API：列出并读取宿主侧镜像的 `/home/root` 内容，供网页预览与快捷运行。
